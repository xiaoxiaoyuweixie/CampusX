## Figma 使用

可直接拖入 Figma，放在白色导航栏中预览。建议使用独立的 24 × 24 图标容器，再按视觉大小调整 PNG 的缩放；原图包含透明留白，五个图形的占比略有差异。页面名称使用独立文本层。

本批为生成的位图素材，路径和描边不能直接作为矢量编辑。放大时可见少量生成边缘残点，常规导航图标尺寸下不明显；如进入最终开发交付，宜按同一网格重绘为矢量并统一轮廓占比。

设计颜色依据：当前选中态 #3B82F6，默认态 #6B7280。本批仅生成蓝色选中态，生成像素色值会有轻微变化。
