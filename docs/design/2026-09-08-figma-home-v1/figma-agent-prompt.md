校园横幅优先使用单独上传的 campus-hero.png，作为可替换的独立图片层放在浅蓝底色之上、标题与搜索等 UI 图层之下。该素材为基于已确认首页进行 AI 编辑还原的 1942×809 PNG，左侧浅蓝留白、右侧为校园建筑，不含文字或 UI；插画细节与参考图可能略有差异，并非原图无损裁切。按横幅容器等比填充，必要时裁切并调整焦点，让建筑保持在右侧；禁止拉伸图片。标题、副标题、学校名称和搜索内容均使用原生可编辑文字，不能烧录进插画。
