- 形式：两张静态 PNG，使用内置 ImageGen 生成。
- 范围：视觉样板与设计说明，不修改项目代码。

## 设计方向

沿用蓝色校园风格，以浅蓝校园插画、明亮白色内容区、真实感商品照片和统一线性图标建立视觉一致性。首页强调资源浏览；详情页强调图片、价格、描述和联系发布者。

## 视觉基准

| 项目 | 建议值 |
| --- | --- |
| 主色 | #3B82F6 |
| 淡蓝底色 | #EFF6FF |
| 页面背景 | #F8FAFC |

尺寸为设计逻辑像素起点。生成图片不保证每个色值或尺寸都精确匹配；后续可编辑稿或开发实现时，以确认后的规范校准。

## 评审重点

1. 首页校园氛围与登录页是否连贯，宣传区和商品列表的视觉权重是否合适。
2. 图片、标题、价格、辅助信息是否容易按顺序阅读。
3. 两页的字体、图标、圆角、留白与底部操作区是否协调。
4. 详情信息是否完整，收藏和联系发布者是否足够清楚。
