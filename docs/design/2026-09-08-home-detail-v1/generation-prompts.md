输入 1：初版首页。输入 2：商品详情，仅作为书本照片参考。

```text

Return only the edited Image 1 home screen, at the SAME dimensions and with the SAME layout, colors, typography, text, icons, hero artwork, tab bar, AI button, card widths, positions, and spacing as Image 1.
Make only these two narrowly scoped consistency corrections:
1. Replace the photograph inside the FIRST LEFT product card (the 高等数学上下册 textbook priced ¥25) with a cropped view of the exact book photograph from the top of Image 2. Preserve the same light-blue covers with the fine-line abstract mathematical pattern, subtle worn edges, two books and sunlit oak desk. Fit it cleanly within the original card image rectangle, so both UI screens visibly show the SAME textbook listing. Do not copy any detail-screen UI into the photo.
2. In the two fully visible first-row product cards, remove the tiny circular photographic seller avatars before the seller names. Keep the text "小林同学" and "阿禾", align them to the existing left text padding, keep "128 浏览" and "76 浏览" on their existing right alignment. All other text remains exact.
Do not alter any other part of the home screenshot. In particular keep "校易通", "西南大学", "搜索校园资源", "校园资源 · 同学之间", all five category labels, all four prices, and the five tabs "首页", "分类", "发布", "消息", "我的" untouched. No new controls, text or decorations. Pixel-sharp UI quality.
```
