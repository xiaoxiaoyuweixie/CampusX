## 统一设计语言

- 主色 #3B82F6；浅蓝 #EFF6FF；页面底色 #F8FAFC；白色内容表面。
- 主文字 #111827，辅助文字 #6B7280，价格强调 #EF4444。
- 中文系统无衬线字体、统一圆角线性图标、轻阴影、清楚的标题与辅助信息层级。
- 校园插画主要用于首页、我的、关于我们；表单与聊天保持清楚、轻量。
- Tab 页面保留 首页 / 分类 / 发布 / 消息 / 我的；二级页面采用返回导航。
- 发布按钮与底部 TabBar 分区呈现；弹窗操作区留有足够间距。

色值和尺寸是设计基准。PNG 由内置 ImageGen 生成，不是可编辑 Figma 文件，也不保证逐像素符合这些标注；各图原始比例予以保留，评审册不会拉伸图稿。
