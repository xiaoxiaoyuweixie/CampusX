# 发布页视觉优化示例 v1

根据用户提供的当前发布页截图，生成一张保留现有业务内容的高保真 UI 示例。

图片：publish-ui.png。提示词：generation-prompt.md。

## 主要调整

- 上传入口使用浅蓝区域、细虚线边框和相机图标，更明确地引导开始填写；最多 9 张保持不变。
- 加强标题、标签、字段值与占位文字的层级，统一卡片圆角、左右边距和行间距。
- 压缩描述区的大块空白，使上传、基本信息和描述三个区域更均衡。
- 发布按钮扩大为接近全宽，增强主操作的识别度。保留底部五个 tab 与发布选中态。
- 顶部补充简短引导文案，保持蓝白校园风格。

## 交付说明

使用 gpt-image-2 技能的 Mode B / Host-Native 流程，以内置 image_gen 生成。此图是 PNG 视觉示例，未直接写入 Figma，也未修改小程序代码。

已目视核对图片上传、标题、分类、价格、面交、描述、发布按钮及五个底部导航均完整呈现，分类为数码电子，未增加新的业务控件。生成图的像素色值、图标与圆角细节需在正式设计稿中校准。
