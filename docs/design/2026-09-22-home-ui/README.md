## 实现内容

- `miniprogram/pages/home/`：调整学校/搜索、校园横幅、五类入口和双列商品的尺寸、间距、颜色；按分类 ID 选择对应图片，保留后台分类名称、排序和未知分类的原图标降级。
- `miniprogram/components/search-bar/`：采用稿件的搜索图标、浅白底和尺寸，保持输入、键盘搜索确认、取消行为。
- `miniprogram/components/product-card/`：新增 `variant="home"`，首页统一采用浅蓝底 `#EFF6FF`，价格、校区、卖家/浏览分行展示。真实标题仍可显示两行，辅助文字采用 20rpx（10px @375px）以便阅读。默认卡片样式保留给分类页。
- 商品封面、标题、价格、校区、卖家、浏览量及推荐顺序继续使用当前接口数据；未引入任何 Figma 示例商品，也没有变更数据库或推荐算法。
- `miniprogram/images/home/` 使用 Figma 对应资产。五个原生 Tab 更新普通/选中图标；消息未读图标基于新图标保留此前确认的红点位置。
- `miniprogram/utils/unread.js` 及其 5 秒轮询、后台暂停、已读刷新、账号隔离逻辑保持不变；使用原图标路径，轮询不会把新版图标换回旧版。
- AI 入口拖动、对话、发送防重、关闭与原生 TabBar 恢复逻辑保持不变。
