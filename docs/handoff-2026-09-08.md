## 4. 登录配置诊断与部署提醒

### 已核实的原因

前端报“管理端接口返回格式异常，请检查 adminService HTTP 访问地址”，是在 `admin-web/src/api/cloud.js` 解析响应 JSON 失败时产生。

此前 `.env` 错把后台静态网页地址作为 API：

```text
https://cloud1-d6g5stkeb92288dee-1445397435.tcloudbaseapp.com/
```

助手向该地址发送无账号密码的 POST 测试，实际收到 `text/html` 的 CampusX 后台页面，不是业务 JSON。

从线上旧版公开脚本核对到接口地址，并验证其空登录请求返回 `{"code":40001,"message":"请输入账号和密码","data":null}`；本地来源的跨域预检也通过。交接时当前 `.env` 已是：

```dotenv
VITE_ADMIN_API_URL=https://cloud1-d6g5stkeb92288dee-1445397435.ap-shanghai.app.tcloudbase.com/adminService
```

- 这是程序调用的接口，不是后台登录网页。用户曾直接在浏览器打开它，因此误以为新地址不可用。
- 直接 GET 该接口时，实测返回“登录已失效，请重新登录”；响应有 `Content-Disposition: attachment`，浏览器也可能下载文件。这不能用于判断登录 POST 是否正常。
- 助手未使用真实管理员密码完成登录；最终验收以用户最新反馈为准。
- 修改 `.env` 后须重启 Vite。浏览器应打开启动终端输出的本地网页地址，而不是云函数接口。
- `spec.md` 的 `ADMIN-HTTP-001` 仍列出旧静态根地址并要求先验证。该具体地址表述已过时，不要照它把当前 `.env` 改回去；后续维护此段时应同步澄清网页地址与 API 地址。
